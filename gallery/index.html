How to read this gallery

Both columns use the same tokens from tokens.json and the generated styles/tokens.css. Only the mode attributes differ. Desk is dense and laptop-sized; Room is projected and much larger. The Room column uses seat codes instead of pupil names.

  • Desk sample: 15 px body text and 32 px minimum targets.
  • Room sample: 32 px body text and 64 px minimum targets.
  • Room shows at most six pupils per page before paging.

Notes

  • This gallery is static. The toggle shows both pressed states; it does not change the page.
  • Hover and focus-visible are shown as static samples in addition to the real CSS states.
  • Room mode uses seat codes; pupil labels stay on the Desk view.
  • Colour is not the only status cue: every status also has a shape and a text label.
  • Reduced motion sets the motion tokens to 0 ms; the skeleton becomes static.
